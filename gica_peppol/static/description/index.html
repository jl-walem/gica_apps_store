GICA Peppol

Peppol integration for Odoo 17 Community

GICA Peppol connects Odoo with external Peppol services operated by Cyber-Relais.

The module supports both outbound and inbound Peppol document processing.

Outbound Peppol Sales

  • Create Peppol sales records from posted invoices
  • Generate UBL BIS 3.0 XML
  • Generate or reuse PDF attachments
  • Send documents through SFTP
  • Track transmission status
  • Multi-company support

Inbound Peppol Purchases

  • Receive vendor invoices through API
  • Store XML, PDF and HTML attachments
  • Create Peppol purchase records
  • Import UBL documents into vendor bills
  • Individual or batch import
  • Vendor bills remain in draft for review

Architecture

Outbound:
Odoo -> UBL/PDF -> Cyber-Relais -> Peppol

Inbound:
Peppol -> Cyber-Relais -> Odoo API -> Vendor Bill Draft

Important note

The inbound API expects a pure UBL Invoice or Credit Note document.

If a Standard Business Document (SBD) is received, the SBD envelope should be extracted by the external Peppol platform before transmission to Odoo.
